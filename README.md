# Fullstack App 🚀

Ce projet est une application Fullstack contenant un backend sous Express et un frontend sous React.

## Déploiement automatique sur Render

Vous pouvez déployer cette application sur Render en un seul clic grâce au bouton ci-dessous :

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Aymane-Oua/fullstack-app)

Une fois que vous aurez cliqué sur le bouton :
1. Connectez-vous à Render si ce n'est pas déjà fait.
2. Render va détecter automatiquement le fichier `render.yaml` et configurer l'ensemble des services.
3. Donnez un nom à votre groupe de services et cliquez sur **Apply**.
